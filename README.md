# Устранение замечаний

Android-приложение для контроля замечаний при передаче квартир, оформленное в фирменной сине-голубой стилистике ГК «СУ-555».

## Возможности

- загрузка Excel-файлов `.xlsx` прямо с телефона;
- автоматическое распознавание колонок таблицы;
- расчёт открытых, устранённых и просроченных замечаний;
- группировка и приоритизация по квартирам;
- список «Что необходимо сделать» с просрочками наверху;
- поиск по квартире, замечанию, категории и ответственному;
- аналитическая вкладка с несколькими графиками;
- экспорт нового Excel-отчёта со сводкой, квартирами, категориями, исходными замечаниями и диаграммами;
- работа с несколькими листами в одной книге Excel;
- обработка Excel выполняется локально на устройстве.

## Какие колонки распознаются

Приложение ищет близкие варианты названий:

- **Квартира**: «Квартира», «№ квартиры», «Номер квартиры», «Кв.»;
- **Замечание**: «Замечание», «Описание замечания», «Дефект», «Нарушение»;
- **Срок**: «Срок устранения», «Плановый срок», «Дата устранения», «Срок»;
- **Статус**: «Статус», «Состояние», «Устранено», «Выполнение»;
- **Ответственный**: «Ответственный», «Подрядчик», «Исполнитель», «Организация»;
- **Категория**: «Вид работ», «Раздел», «Категория», «Тип замечания»;
- **Дата выявления**: «Дата выявления», «Дата замечания», «Дата регистрации».

Для анализа обязательно нужны колонки, по которым можно определить **квартиру** и **описание замечания**. Формат `.xls` старого типа пока не поддерживается — его нужно сохранить как `.xlsx`.

# Устранение замечаний

Android-приложение для работы с замечаниями при передаче квартир на объекте **Мироновская, д. 30**.

Текущая версия: **beta 0.4.0**.

## Объект

Всего **568 квартир**:

- корпус 1, секция 1 — квартиры 1–161;
- корпус 1, секция 2 — квартиры 162–269;
- корпус 2, секция 1 — квартиры 1–161;
- корпус 2, секция 2 — квартиры 162–299.

## Цветовые статусы Excel

Приложение читает заливку исходного XLSX:

- зелёный `#92D050` — выполнено;
- белый / без заливки — не выполнено;
- оранжевый `#FFC000` — обратить внимание;
- синий `#00B0F0` — отчитано как выполненное, но по факту не принято.

## Beta 0.4.0 — рабочий журнал

После загрузки Excel данные сохраняются в локальной базе телефона. Повторно выбирать файл после каждого запуска не нужно.

В приложении доступны:

- создание новых замечаний прямо в квартире;
- редактирование описания, элемента, подрядчика, срока и статуса;
- быстрые изменения статуса из карточки;
- перенос замечаний в архив и восстановление;
- история изменений каждого замечания;
- фотографии «до / проверка» и «после» через камеру;
- массовое изменение открытых замечаний квартиры;
- последовательный режим обхода квартир;
- ежедневная сводка в 08:00 по просроченным квартирам и срокам;
- фильтрация и поиск квартир;
- отчёт для руководства;
- экспорт актуального состояния обратно в XLSX.

## Группировка подрядчиков

Для управленческой аналитики подрядчики нормализуются:

- **МКД → СМУ**;
- **СТМ → СМУ**;
- **Электрика / электрики → УИР**;
- **Сантехника / сантехники → УИР**.

Комбинированные записи разделяются. Например, `СМУ+Новатекс` добавляет одно замечание в статистику **СМУ** и одно — в статистику **Новатекс**. Исходное значение подрядчика остаётся в карточке замечания.

## Excel-отчёт

Экспорт содержит листы:

- «Руководителю»;
- «Секции»;
- «Квартиры»;
- «Подрядчики»;
- «Детали».

Выгрузка строится по текущей локальной базе, поэтому в неё попадают изменения, сделанные непосредственно в приложении.
